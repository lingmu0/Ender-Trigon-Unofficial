# Ender Trigon Unofficial

An unofficial NeoForge port of
[Ender Trigon](https://github.com/nonamecrackers2/ender-trigon) for
Minecraft 1.21.1.

The original mod and assets are by nonamecrackers2. This port keeps the
upstream Java package for attribution and compatibility, while published
content uses the `ender_trigon_unofficial` mod and resource namespace.

## Building

Use Java 21 and run:

```powershell
.\gradlew.bat build
```
